# RunAsSystem

Utility to run PowerShell/commands as SYSTEM via PsExec (`PS_as_System.ps1`, `PsExec.exe`, `runassystem.cmd`) — useful for testing Win32 app installs the same way Intune runs them.

📖 Full guide: https://scloud.work/en/testing-applications-system-context-psexec/

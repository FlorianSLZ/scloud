# Registry Key with Intune

Three ways to enforce a registry key via Intune: a standalone script (`Set-RegistryKey.ps1`), a Proactive Remediation detect/remediate pair (`Remediation/`), and a packaged Win32 app (`win32-RegistryKey/`).

# Windows and Intune Bug Fixes (PowerShell)

> A collection of PowerShell fixes for Windows issues on Intune-managed devices, such as Start menu and search problems.

## Overview

Troubleshooting scripts for Windows problems I ran into while managing devices with Microsoft Intune. Each subfolder holds the fix for one issue.

## What's included

| Folder | Description |
|--------|-------------|
| [`StartMenu-Search-Office-OneDrive_Clickshare`](StartMenu-Search-Office-OneDrive_Clickshare) | Fixes for an unresponsive Start menu and search, Office login and OneDrive shell folder permission problems, including the Clickshare calendar integration |

## Usage

Open the subfolder, read its README and run the scripts in the order and context described there.
